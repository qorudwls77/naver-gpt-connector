네이버 ↔ 챗GPT 연동 사이트

이 사이트는 챗GPT가 네이버 검색/블로그 콘텐츠/구글 트렌드를 조회할 수 있도록 해주는 중간 API입니다.

1. 네이버 카테고리 검색

GET /api/search?query=검색어&type=blog

type: blog, news, book, encyc, cafearticle, kin, local, webkr, image, shop, doc, movie

2. 네이버 URL 콘텐츠 확인

GET /api/content?url=https://blog.naver.com/아이디/글번호

3. 구글 트렌드 조회 (무료)

GET /api/trends?keyword=검색어&geo=KR

챗GPT Custom GPT의 Actions에 연결하려면 openapi.yaml을 스키마로 등록하세요.
